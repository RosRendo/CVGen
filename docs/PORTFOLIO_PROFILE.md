## 6. Developer Tools & Platforms Specification

Listing only 3 to 5 generic tools gives the impression of a classroom beginner. A production-ready full-stack developer demonstrates fluency across an organized toolkit of 8–12 tools, cleanly separated from coding technologies.

### 6.1 The Core Recommended Tools
1. **Git & GitHub (Essential):** Version control, branches, commits, repository management, PR reviews, and team collaboration.
2. **Visual Studio Code (Essential):** Primary development environment, debugging, extensions, terminal, and code navigation.
3. **Postman (Essential):** Testing REST endpoints, authentication headers, request payloads, and response status codes.
4. **Docker & Docker Compose (Strong fit):** Containerizing backend microservices and databases; managing local or server environments.
5. **pgAdmin / DBeaver (Strong fit):** Inspecting PostgreSQL tables, running SQL queries, exploring relationships, and debugging data.
6. **Linux / Bash (Strong fit):** Working with Ubuntu servers, shell commands, environment variables, logs, and process inspection.
7. **Figma (UI/UX):** Interface wireframes, UI layouts, component design, and design-system exploration.
8. **AWS EC2 (Cloud):** Hosting applications, configuring server environments, and understanding deployment infrastructure.
9. **Nginx & PM2 (Server Operations):** Reverse proxy configuration, SSL termination, process management, and auto application restarts.

### 6.2 Additional Tools Worth Listing (Hands-On Verified)
- **Prisma Studio:** Inspecting and managing database records visually through Prisma ORM.
- **Swagger / OpenAPI:** Documenting, visualizing, and testing interactive backend REST APIs.
- **Playwright:** Automated browser-based end-to-end integration and smoke testing.
- **GitHub Actions:** Automating test runners and deployment workflows.
- **Vercel:** Rapid deployment, preview builds, and frontend edge hosting.

### 6.3 Crucial Separation of Concerns
To ensure fast recruiter scanning and prevent the CV from looking like an unorganized software list:
- **Technologies (Syntax & Code):** TypeScript, React, Next.js, NestJS, Node.js, PostgreSQL, Prisma, REST APIs.
- **Developer Tools (Local & Inspection):** VS Code, Git, GitHub, Postman, DBeaver, pgAdmin, Prisma Studio, Figma.
- **Platforms & Operations (Infrastructure):** Docker, Docker Compose, Linux / Bash, Nginx, PM2, AWS EC2, Vercel.

### 6.4 The Compact Categorized CV Layout
Instead of nine separate bullet points or decorative dots that waste vertical page space, use this compact categorized layout:
